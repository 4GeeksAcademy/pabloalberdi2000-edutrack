## 🚀 Quick Start: Execution Steps

### Option 1: Run on Supabase (Recommended)

1. **Open Supabase SQL Editor**
   - Go to your Supabase project
   - Click "SQL Editor" in the left sidebar

2. **Execute Database Schema**
   - Copy the entire contents of `edutrack.sql` (original Supabase version)
   - Paste into SQL Editor
   - Click "Run"
   - Verify tables are created with `.table` command

3. **Execute Audit Queries**
   - Copy contents of `sql_audit_queries.sql`
   - Paste into SQL Editor
   - Execute in sections (Q1-Q5, then Q6-Q8, then Q9-Q12)
   - Review results at each stage

### Option 2: Run on PostgreSQL Local

```bash
# 1. Create database
createdb edutrack

# 2. Load schema
psql edutrack < edutrack_sqlite.sql

# 3. Execute queries
psql edutrack < queries_q1_to_q12.sql

# 4. View results
psql edutrack < sql_audit_queries.sql
```

### Option 3: Run on SQLite3

```bash
# 1. Initialize database
sqlite3 edutrack.db < edutrack_sqlite.sql

# 2. Run audit queries
sqlite3 -header -column edutrack.db < queries_q1_to_q12.sql

# 3. Export results
sqlite3 -json edutrack.db < sql_audit_queries.sql > results.json
```

## 📞 Support & Troubleshooting

### Common Issues

**Issue:** "Table does not exist" error
- **Solution:** Run `edutrack.sql` or `edutrack_sqlite.sql` first to initialize schema

**Issue:** No results for Q3 (NULL instructors)
- **Solution:** This is correct after Q7 runs. Check before/after results.

**Issue:** Different record counts than expected
- **Solution:** Verify Q6, Q7, Q8 operations completed. Check data integrity queries.

**Issue:** Negative total_revenue in Q12
- **Solution:** Check for negative monthly_fee_paid values (should not exist)
